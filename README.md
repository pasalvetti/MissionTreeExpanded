# Mission Tree Expanded
_A mod for KSP2 Redux adding 15 new missions to the mission tree._

This mod aims to enrich the mission tree as well as smooth out the difficulty of progressing from one primary mission to another by adding intermediate steps when necessary. The base game expects you to go into orbit around the Mun immediately after reaching Kerbin orbit, as well as to land on Duna immediately after landing on Minmus. Adding additional missions helps better guide new players.

In addition, a dozen new secondary missions are proposed to encourage the player to further explore each visited planet (for example, by leading the player to Discoverable locations) or to achieve feats that are not required in the base game (entering polar orbit, setting up a research station on the North Pole, etc.).

The mod also reorganizes a few existing missions so they fit the expanded tree: Dress Rehearsal is available from the start of a campaign, Disco Party is unlocked by Mun or Bust, and some rewards are rebalanced.

## Requirements
This version requires [KSP2 Redux](https://ksp2redux.org). It does not work with the original game.

## Installation
1. Open the game folder by right-clicking on the game in your Steam library, selecting "Manage," and then clicking "Browse local files."
2. Download the latest version of this mod from [GitHub](https://github.com/pasalvetti/MissionTreeExpanded/releases).
3. In the game folder, create a `mods/MissionTreeExpanded` folder.
4. Extract the content of the zip file into `mods/MissionTreeExpanded`.
